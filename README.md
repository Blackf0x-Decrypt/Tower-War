# Игра, где лучший игрок меняет правила

Вы играете против трёх ботов. Захватывайте здания, добывайте золото и древесину, улучшайте экономику. Через четыре минуты лидер по заработанным ресурсам получает право вводить приказы, меняющие игру.

## Быстрый запуск на Windows

1. Установите **Node.js 22.13 или новее** с https://nodejs.org/ — выбирайте установщик для своей системы. Если он уже установлен, этот шаг не нужен.
2. Полностью распакуйте архив, например в `C:\Games\TowerWar`. **Не запускайте игру внутри ZIP.**
3. Откройте `START-WINDOWS.cmd` двойным кликом.
4. При первом запуске автоматически установятся зависимости. Для этого нужен интернет; дождитесь окончания установки.
5. Когда в окне появится строка `Local`, откройте в браузере **http://localhost:3001**.
6. Нажмите **«В бой!»**. Окно запуска оставьте открытым. Для выхода остановите сервер сочетанием **Ctrl+C**.

Для повторного запуска просто снова откройте `START-WINDOWS.cmd`.

## macOS / Linux

Установите Node.js 22.13 или новее с https://nodejs.org/. Распакуйте архив, откройте терминал в папке игры и выполните:

```
bash START-MAC-LINUX.sh
```

Затем откройте **http://localhost:3001**. Не закрывайте терминал во время игры.

## Как играть

- Нажмите свою синюю башню, затем цель — отправится отряд. Пути по умолчанию автоматические; их можно остановить в панели выбранной башни.
- Перетаскивайте поле мышью, меняйте масштаб колёсиком или кнопками +/−. Кнопка «Обзор» показывает карту.
- Штаб создаёт бойцов. Шахты дают золото, лесопилки — древесину. Больше людей внутри — выше добыча.
- Улучшайте выбранные здания и пушки за ресурсы. Шахты и лесопилки не стреляют.
- Первые **4 минуты** — развитие. Затем право приказа получает лидер по **всему заработку за матч**, а не по текущему остатку кошелька.
- Приказ нужно набирать вручную: вставка отключена, после начала ввода есть **10 секунд**. Бой не останавливается, лидерство можно потерять.
- Иногда такое же поле отправляет сообщение над штабом. Оно специально выглядит так же, как поле приказа.
- Матч длится до 12 минут. Побеждает экономический лидер, если бой не завершился раньше.

## Нужен ли ключ? Нет — для начала игры не нужен

Без ключа работает обычный матч и встроенный набор простых приказов. Например:

- `Дай моему главному зданию 100 бойцов`
- `Все красные теперь мои`
- `Заморозь врагов на 30 секунд`

Свободные формулировки без ключа могут не распознаваться. Рулетка штрафов по умолчанию **выключена**, потому что для неё нужен DeepSeek. Прямой запрос «я победил» запрещён.

## Необязательно: подключить свой DeepSeek

Ключей автора в архиве нет. Для произвольных формулировок нужен **собственный API-ключ DeepSeek** с доступом к API. Запросы расходуют средства вашего аккаунта.

1. Скопируйте файл `.env.example` в этой же папке и назовите копию `.env`.
2. Откройте `.env` обычным текстовым редактором и впишите свой ключ после `DEEPSEEK_API_KEY=`. Не добавляйте пробелы.
3. `DEEPSEEK_MODEL` содержит используемую проектом модель. Если API сообщает, что она недоступна, укажите идентификатор модели, доступной вашему аккаунту.
4. Остановите сервер через Ctrl+C и запустите заново.
5. Теперь при желании включите рулетку штрафов в настройках игры.

В Windows включите показ расширений имён файлов, чтобы случайно не создать `.env.txt`. Не отправляйте свой `.env` другим людям. Ключ читается сервером; вводить его в игровой приказ не нужно.

## Если не запускается

- **Окно сообщает, что Node.js не найден:** установите его и заново откройте окно запуска; при необходимости перезагрузите компьютер.
- **Ошибка npm ci:** проверьте интернет, версию Node.js и запустите файл ещё раз. На первом запуске скачиваются зависимости для вашей ОС.
- **Порт занят или Local показывает другой адрес:** закройте ранее запущенную копию игры или используйте адрес из строки `Local`.
- **Страница не открывается:** дождитесь `Local`; убедитесь, что окно сервера всё ещё открыто.
- **Приказ не распознан:** без ключа попробуйте один из примеров выше. Для свободного текста подключите собственный DeepSeek.
- **Для рулетки нужен DeepSeek:** отключите её в настройках или добавьте свой ключ.

Запуск вручную из папки проекта:

```
npm ci
npm run dev -- --port 3001 --host 127.0.0.1
```

Это исходный проект с локальным сервером, а не отдельный exe. Сервер запускается только на вашем компьютере. Записи матчей из ролика и личные файлы автора в эту версию не входят. Сборка проверена на macOS; непосредственно на Windows эта версия пока не тестировалась.
